2. Use Tailwind CSS v4 and shadcn-vue.
3. Base final colors on the official IUGM logo.
4. Blue is primary; green is secondary; neutral/light surfaces dominate.
5. Use semantic design tokens.
6. Build mobile-first.
7. Verify keyboard focus, contrast, reduced motion, and semantic structure.
8. Use authentic institutional photography for final content.
9. Never invent statistics or official claims.
