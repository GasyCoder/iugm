---
name: laravel-backend
description: Use when implementing, fixing, refactoring, testing, or reviewing Laravel 13 backend/API code, database schema, validation, authorization, or Eloquent behavior.
---

1. Inspect relevant routes, models, controllers, requests, resources, policies, migrations, and tests.
2. Follow existing conventions.
3. Keep controllers thin.
4. Use Form Requests for meaningful validation.
5. Use API Resources for public JSON representation.
6. Use policies/gates for protected behavior.
7. Avoid N+1 queries.
8. Use transactions for atomic multi-write workflows.
9. Add/update tests.
10. Run targeted tests, then broader checks when practical.
11. Never run destructive DB commands against an unknown environment.
